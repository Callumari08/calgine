\doxysubsection{Detailed Description}
Base class for all \doxylink{namespaceCalgine}{Calgine} applications. 

The \doxylink{classCalgine_1_1App}{App} class manages the core application lifecycle, including system initialization, the main game loop, event handling, and rendering. User applications can either instantiate \doxylink{classCalgine_1_1App}{App} directly or derive from it to add custom functionality.

The \doxylink{classCalgine_1_1App}{App} class handles\+:
\begin{DoxyItemize}
\item SDL3 and Open\+GL initialization
\item \doxylink{classCalgine_1_1Window}{Window} management through \doxylink{classCalgine_1_1WindowHandler}{Window\+Handler}
\item Main loop execution with tick updates (preloop, update, late\+\_\+update)
\item SDL event processing (window close, quit events)
\item Rendering for all active windows
\item \doxylink{classCalgine_1_1GameObject}{Game\+Object} hierarchy lifecycle management
\end{DoxyItemize}\hypertarget{classCalgine_1_1App_autotoc_md0}{}\doxysubsubsection{\texorpdfstring{Configuration}{Configuration}}\label{classCalgine_1_1App_autotoc_md0}
Applications can be configured through the public {\ttfamily settings} member variable before calling \doxylink{classCalgine_1_1App_a52ea702157554748e98b84dc0132e39f}{systems\+\_\+init()}. The \doxylink{structCalgine_1_1AppSettings}{App\+Settings} structure provides options for\+:
\begin{DoxyItemize}
\item Application name (used for logging and window titles)
\item Default VSync state for windows
\end{DoxyItemize}\hypertarget{classCalgine_1_1App_autotoc_md1}{}\doxysubsubsection{\texorpdfstring{Basic Usage}{Basic Usage}}\label{classCalgine_1_1App_autotoc_md1}

\begin{DoxyEnumerate}
\item Create an \doxylink{classCalgine_1_1App}{App} instance (or derive from \doxylink{classCalgine_1_1App}{App} for custom functionality)
\item Configure app settings (optional)
\item Call \doxylink{classCalgine_1_1App_a52ea702157554748e98b84dc0132e39f}{systems\+\_\+init()} to initialize SDL, Open\+GL, and create windows
\item Set up your \doxylink{classCalgine_1_1GameObject}{Game\+Object} hierarchy and attach \doxylink{classCalgine_1_1Behaviour}{Behaviour} components
\item Call \doxylink{classCalgine_1_1App_a25b8f54a7509d91d9a577d85568c31b7}{main\+\_\+loop()} to start the application
\end{DoxyEnumerate}

{\footnotesize\ttfamily void Calgine\+::\+App\+::main\+\_\+loop (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption})}



Runs the main application loop until all windows are closed. 

Before entering the loop, this method calls preloop\+\_\+tick() once on all Game\+Objects in the hierarchy. Then, each frame executes the following steps\+:
\begin{DoxyEnumerate}
\item Processes SDL events (window close, quit, etc.)
\item Calls update\+\_\+tick() on all Behaviours attached to Game\+Objects
\item Calls late\+\_\+tick() on all Behaviours attached to Game\+Objects
\item Renders all active windows
\item Processes pending \doxylink{classCalgine_1_1GameObject}{Game\+Object} deletions
\item Cleans up closed windows
\end{DoxyEnumerate}

The loop continues until either SDL\+\_\+\+EVENT\+\_\+\+QUIT is received or all windows have been closed.

Initializes all required systems (SDL3, Open\+GL, logging). 

\begin{DoxyWarning}{Warning}
Do NOT call directly! use the \doxylink{classCalgine_1_1App_a96e9ed6ce1f9d49d30e334f8633684bf}{start\+\_\+systems()} inline function! This will break Im\+GUI otherwise!!!
\end{DoxyWarning}
This method must be called before \doxylink{classCalgine_1_1App_a25b8f54a7509d91d9a577d85568c31b7}{main\+\_\+loop()}. It performs the following\+:
\begin{DoxyItemize}
\item Initializes the logging system with the application name
\item Sets up SDL3 video subsystem
\item Configures Open\+GL context attributes (Open\+GL 4.\+5 Core Profile)
\item Creates initial windows through \doxylink{classCalgine_1_1WindowHandler}{Window\+Handler}
\item Initializes GLAD2 for Open\+GL function loading 
\end{DoxyItemize}
