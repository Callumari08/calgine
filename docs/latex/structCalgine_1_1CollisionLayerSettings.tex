\doxysubsection{Detailed Description}
Named collision layers and which pairs of layers collide. 

Every \doxylink{classCalgine_1_1RigidBody}{Rigid\+Body} belongs to one layer (\doxylink{structCalgine_1_1RigidBodySettings_a24715530baa74d7416b498d59d2780bb}{Rigid\+Body\+Settings\+::layer}). Two bodies only collide if their layers are set to collide with each other. By default there is one named layer, "{}default"{}, and every layer collides with every other layer.
