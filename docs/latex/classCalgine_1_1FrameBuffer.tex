\doxysubsection{Detailed Description}
Manages Open\+GL Framebuffer Objects for offscreen rendering. 

\doxylink{classCalgine_1_1FrameBuffer}{Frame\+Buffer} encapsulates the creation and management of Open\+GL FBOs (Framebuffer Objects). It handles both color texture attachments and depth renderbuffer attachments, and provides simple bind/\+unbind functionality for rendering to texture.
