Formats arguments according to the format string {\ttfamily fmt\+\_\+str} and produces a string of the exact required size at compile time. Both the format string and the arguments must be compile-\/time expressions.

The resulting string can be accessed as a C string via {\ttfamily c\+\_\+str()} or as a {\ttfamily fmt\+::string\+\_\+view} via {\ttfamily str()}.

{\bfseries{Example}}\+: \begin{DoxyVerb}// Produces the static string "42" at compile time.
static constexpr auto result = FMT_STATIC_FORMAT("{}", 42);
const char* s = result.c_str();
\end{DoxyVerb}
