\doxysubsection{Detailed Description}
Base class for all behaviour components that can be attached to Game\+Objects. 

\doxylink{classCalgine_1_1Behaviour}{Behaviour} provides the component-\/based functionality for Game\+Objects. By inheriting from \doxylink{classCalgine_1_1Behaviour}{Behaviour} and overriding its virtual tick methods, you can create custom game logic that responds to different phases of the game loop.\hypertarget{classCalgine_1_1Behaviour_autotoc_md2}{}\doxysubsubsection{\texorpdfstring{Lifecycle}{Lifecycle}}\label{classCalgine_1_1Behaviour_autotoc_md2}
When a \doxylink{classCalgine_1_1Behaviour}{Behaviour} is added to a \doxylink{classCalgine_1_1GameObject}{Game\+Object}\+:
\begin{DoxyEnumerate}
\item The \doxylink{classCalgine_1_1Behaviour}{Behaviour} is constructed
\item attach\+\_\+owner() is called internally to link it to the \doxylink{classCalgine_1_1GameObject}{Game\+Object}
\item \doxylink{classCalgine_1_1Behaviour_ae4ed175037ecf4cc620bbcd83b9943ba}{start\+\_\+tick()} is called once
\item \doxylink{classCalgine_1_1Behaviour_a61aeb7ae491ffb5b6a4b90d24a38c1bd}{update\+\_\+tick()} and \doxylink{classCalgine_1_1Behaviour_aebecb028feb9cc0087c227a80b663f6c}{late\+\_\+tick()} are called every frame while enabled
\item \doxylink{classCalgine_1_1Behaviour_aab60143ff0527a6db745d286dec38fca}{on\+\_\+destroy()} is called when the \doxylink{classCalgine_1_1GameObject}{Game\+Object} is destroyed
\end{DoxyEnumerate}\hypertarget{classCalgine_1_1Behaviour_autotoc_md3}{}\doxysubsubsection{\texorpdfstring{Tick Methods}{Tick Methods}}\label{classCalgine_1_1Behaviour_autotoc_md3}
Override these protected virtual methods to implement your game logic\+:
\begin{DoxyItemize}
\item {\bfseries{\doxylink{classCalgine_1_1Behaviour_a9f57fdc9e7cf4f2caae45df243baacea}{preloop\+\_\+tick()}}}\+: Called once before the main loop starts (only for behaviours added before the loop)
\item {\bfseries{\doxylink{classCalgine_1_1Behaviour_ae4ed175037ecf4cc620bbcd83b9943ba}{start\+\_\+tick()}}}\+: Called once when the behaviour is first attached
\item {\bfseries{\doxylink{classCalgine_1_1Behaviour_a61aeb7ae491ffb5b6a4b90d24a38c1bd}{update\+\_\+tick()}}}\+: Called every frame during the update phase
\item {\bfseries{\doxylink{classCalgine_1_1Behaviour_aebecb028feb9cc0087c227a80b663f6c}{late\+\_\+tick()}}}\+: Called every frame after update, useful for cameras and follow logic
\item {\bfseries{\doxylink{classCalgine_1_1Behaviour_aab60143ff0527a6db745d286dec38fca}{on\+\_\+destroy()}}}\+: Called when the \doxylink{classCalgine_1_1GameObject}{Game\+Object} is being destroyed
\end{DoxyItemize}\hypertarget{classCalgine_1_1Behaviour_autotoc_md4}{}\doxysubsubsection{\texorpdfstring{Usage Example}{Usage Example}}\label{classCalgine_1_1Behaviour_autotoc_md4}
