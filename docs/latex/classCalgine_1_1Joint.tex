\doxysubsection{Detailed Description}
Connects this \doxylink{classCalgine_1_1GameObject}{Game\+Object}\textquotesingle{}s \doxylink{classCalgine_1_1RigidBody}{Rigid\+Body} to another \doxylink{classCalgine_1_1RigidBody}{Rigid\+Body}, or to the world. 

Needs a \doxylink{classCalgine_1_1RigidBody}{Rigid\+Body} on the same \doxylink{classCalgine_1_1GameObject}{Game\+Object}. The joint is created once both bodies exist (it waits if either hasn\textquotesingle{}t started yet). If the connected body is destroyed, the joint breaks and stays broken.
