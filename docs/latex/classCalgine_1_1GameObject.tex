\doxysubsection{Detailed Description}
Game\+Objects are objects within the \doxylink{classCalgine_1_1Hierarchy}{Hierarchy} that have multiple \doxylink{classCalgine_1_1Behaviour}{Behaviour} subclasses attached to them which execute code. 

\doxylink{classCalgine_1_1GameObject}{Game\+Object} is the fundamental building block of \doxylink{namespaceCalgine}{Calgine} applications. Game\+Objects form a hierarchical tree structure where each \doxylink{classCalgine_1_1GameObject}{Game\+Object} can have multiple child Game\+Objects and multiple attached \doxylink{classCalgine_1_1Behaviour}{Behaviour} components that define its functionality.\hypertarget{classCalgine_1_1GameObject_autotoc_md6}{}\doxysubsubsection{\texorpdfstring{Key Features}{Key Features}}\label{classCalgine_1_1GameObject_autotoc_md6}

\begin{DoxyItemize}
\item {\bfseries{Hierarchical Structure}}\+: Game\+Objects can have parent and children relationships
\item {\bfseries{Component System}}\+: Attach multiple \doxylink{classCalgine_1_1Behaviour}{Behaviour} subclasses to add functionality
\item {\bfseries{Lifecycle Management}}\+: Automatic memory management with deferred deletion
\item {\bfseries{Enable/\+Disable}}\+: Control whether a \doxylink{classCalgine_1_1GameObject}{Game\+Object} and its behaviours are active
\end{DoxyItemize}\hypertarget{classCalgine_1_1GameObject_autotoc_md7}{}\doxysubsubsection{\texorpdfstring{Usage Example}{Usage Example}}\label{classCalgine_1_1GameObject_autotoc_md7}

Marks this \doxylink{classCalgine_1_1GameObject}{Game\+Object} and all its children for destruction. 

Calls on\+\_\+destroy() on all attached behaviours, recursively destroys all children, and detaches from parent. The actual memory deallocation happens later via \doxylink{classCalgine_1_1GameObject_ad47e6d97336652e235aa1b5e20daa5ef}{process\+\_\+pending\+\_\+deletes()} to ensure safe cleanup during iteration.

\begin{DoxyNote}{Note}
This function is idempotent -\/ calling it multiple times has no additional effect. 
\end{DoxyNote}
