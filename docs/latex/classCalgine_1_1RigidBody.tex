\doxysubsection{Detailed Description}
Gives a \doxylink{classCalgine_1_1GameObject}{Game\+Object} a body in the \doxylink{classCalgine_1_1PhysicsWorld}{Physics\+World}. 

The body is created in start\+\_\+tick() from the \doxylink{classCalgine_1_1GameObject}{Game\+Object}\textquotesingle{}s {\itshape world} transform. The collider size is multiplied by the world scale at that moment.


\begin{DoxyItemize}
\item dynamic\+: physics writes the result of every step back into the \doxylink{classCalgine_1_1GameObject}{Game\+Object}\textquotesingle{}s transform. Changing the \doxylink{classCalgine_1_1Transform}{Transform} yourself has no effect on the body; use \doxylink{classCalgine_1_1RigidBody_a11b9531e8a491f56d645c46f93ff18f2}{teleport()} or velocities/forces.
\item kinematic\+: the body follows the \doxylink{classCalgine_1_1GameObject}{Game\+Object}\textquotesingle{}s world transform every step. Move the \doxylink{classCalgine_1_1GameObject}{Game\+Object} (or its parent) and the body sweeps there, pushing dynamic bodies out of the way. Move kinematic bodies (and any parent that carries them) in \doxylink{classCalgine_1_1Behaviour_aa20a9f9fea54e6dd8d64ad331da13734}{fixed\+\_\+update\+\_\+tick()}, using \doxylink{classCalgine_1_1Time_a812eed673100109263c73a08ab5f6d8b}{Time\+::fixed\+\_\+delta\+\_\+time()}. Physics steps run before \doxylink{classCalgine_1_1Behaviour_a62c7640f82c8dc7bca360d31b5a07a66}{update\+\_\+tick()}, so movement made in \doxylink{classCalgine_1_1Behaviour_a62c7640f82c8dc7bca360d31b5a07a66}{update\+\_\+tick()} only reaches the body on the next frame\+: the collider trails the mesh by one frame of motion, which grows with frame time under load. Movement from \doxylink{classCalgine_1_1Behaviour_a62c7640f82c8dc7bca360d31b5a07a66}{update\+\_\+tick()} also lands in a single physics step, so the body jumps instead of sweeping smoothly.
\item static\+: never moves. Use \doxylink{classCalgine_1_1RigidBody_a11b9531e8a491f56d645c46f93ff18f2}{teleport()} if you really need to move it.
\end{DoxyItemize}

Disabling the \doxylink{classCalgine_1_1GameObject}{Game\+Object} (set\+\_\+active(false)) removes the body from the simulation until re-\/enabled.

Rendering\+: with interpolation on (the default), moving bodies are drawn at a pose blended between the last two physics steps, through \doxylink{classCalgine_1_1GameObject_add4af37ba603b402213a5cd19611bc9d}{Game\+Object\+::get\+\_\+render\+\_\+matrix()}. The logical \doxylink{classCalgine_1_1Transform}{Transform} still holds the latest simulated pose, so game code reading it sees where the body really is.

Scale\+: the collider is built from the world scale when the body is created. Call \doxylink{classCalgine_1_1RigidBody_a710f588292b70608a5aefe79a8ed7580}{refresh\+\_\+shape()} after changing scale, or set \doxylink{structCalgine_1_1RigidBodySettings_ada58d3e3c122ce5b1783bbc13d63c40e}{Rigid\+Body\+Settings\+::track\+\_\+scale} to do it automatically.
