\doxysubsection{Detailed Description}
Singleton manager for all application windows. 

\doxylink{classCalgine_1_1WindowHandler}{Window\+Handler} provides centralized management of all \doxylink{classCalgine_1_1Window}{Window} instances in the application. It follows the singleton pattern to ensure a single point of control for window lifecycle management, including creation, retrieval, and cleanup of closed windows.

Windows are stored as unique\+\_\+ptr instances, with the \doxylink{classCalgine_1_1WindowHandler}{Window\+Handler} maintaining sole ownership of all managed windows.
