\doxysubsection{Detailed Description}
This is the class from which all user applications derive from. 

To get started with programming an application, you must first create your own class that derives from {\ttfamily \doxylink{classApp}{App}}, where the class name is the name of your app. You must first, before any of your code (except in specific instances where you want to use different libraries etc), call {\ttfamily \doxylink{classApp_a80bce247230188c2d289aed2978f9a59}{systems\+\_\+init}}, then run any (if at all) setup code.

You must {\bfseries{then}} instantiate your behaviours (this can also be done at tick time, however be warned that the {\ttfamily awake} tick will not be called).
