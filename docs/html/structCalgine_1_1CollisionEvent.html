Detailed Description

Submitted to the EventContext by the physics system when two RigidBodies start or stop touching.

Events are submitted during the fixed_update phase (right after the physics step) and stay readable for the rest of that frame: later fixed steps, update, late_update, render, imgui_render and final. They are cleared when the next frame enters fixed_update.

void update_tick(EventContext& event_context) override
{
for (const CollisionEvent* collision : event_context.get_events<CollisionEvent>())
{
if (collision->type == CollisionEvent::enter && collision->involves(get_game_object()))
print("Hit {}", collision->other(get_game_object())->get_name());
}
}
