void Calgine::GameObject::set_parent ( GameObject * parent,
bool keep_world_transform = true )

Moves this GameObject under a new parent.

Parameters
parentThe new parent. Must not be this object or one of its descendants.
keep_world_transformIf true (default), the local transform is recalculated so the object stays where it is in the world. If false, the local transform is kept as-is.
