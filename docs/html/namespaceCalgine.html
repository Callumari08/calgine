enum class Calgine::MotionType

How a RigidBody moves.

Enumerator
static_body 

Never moves (floors, walls).

kinematic 

Moved by code through its GameObject's Transform; pushes dynamic bodies but isn't pushed back.

dynamic 

Fully simulated: gravity, forces and collisions move it. Physics owns its Transform.
