Detailed Description

Singleton manager for all application windows.

WindowHandler provides centralized management of all Window instances in the application. It follows the singleton pattern to ensure a single point of control for window lifecycle management, including creation, retrieval, and cleanup of closed windows.

Windows are stored as unique_ptr instances, with the WindowHandler maintaining sole ownership of all managed windows.

Remove all windows that have been marked for closure.

Iterates through all managed windows and removes those that have had request_close() called on them. This frees the memory associated with closed windows.
