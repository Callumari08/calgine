Detailed Description

Connects this GameObject's RigidBody to another RigidBody, or to the world.

Needs a RigidBody on the same GameObject. The joint is created once both bodies exist (it waits if either hasn't started yet). If the connected body is destroyed, the joint breaks and stays broken.

JointSettings hinge;
hinge.type = JointType::hinge;
hinge.connected_body = frame.get_behaviour<RigidBody>();
hinge.anchor = glm::vec3(-1.0f, 0.0f, 0.0f); // door's left edge
hinge.axis = glm::vec3(0.0f, 1.0f, 0.0f);
door.add_behaviour<Joint>(hinge);
