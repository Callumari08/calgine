Detailed Description

The engine's physics simulation (backed by Jolt Physics).

The App owns the lifecycle: the world is created in App::systems_init(), stepped once per fixed timestep right after every Behaviour's fixed_update_tick(), and shut down when the App is destroyed.

Add a RigidBody behaviour to a GameObject to give it a body in this world. Collisions are reported through the EventContext as CollisionEvent (see collision_event.h).

Called on the main thread after every physics step with that step's stats.

A frame can run zero or several steps, so use this rather than polling get_last_step_stats() when every step needs to be recorded (e.g. benchmarks). Pass nullptr to clear.
