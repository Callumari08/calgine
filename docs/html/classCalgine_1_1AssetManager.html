◆ load_input_config()

std::unordered_map< std::string, ActionMap > Calgine::AssetManager::load_input_config ( const std::string &  file_path)

Load input action maps from a TOML file

Parameters
file_pathPath to the TOML config file (e.g., "assets/config/input.toml")
Returns
Map of action map name to ActionMap

Example TOML format:

[Gameplay]
Move = [
{ type = "keyboard", input = "W", contribution = [0, 1] },
{ type = "keyboard", input = "A", contribution = [-1, 0] },
]
Jump = [
{ type = "keyboard", input = "Space", contribution = [true] },
]

Supported input types: "keyboard", "mouse_button", "mouse_move", "mouse_wheel" Contribution array: [value] for button/axis, [x, y] for vec2, [x, y, z] for vec3
